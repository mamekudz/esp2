# Printable part groups

Outputs are sorted by **print color**, not by assembly step:

| Folder | Typical parts |
| --- | --- |
| `beige/` | Upper enclosure / monitor / drive bodies |
| `gray/` | Bottom plate |
| `brown/` | One-piece keyboard |
| `black/` | Drive front inserts |
| `white/` | Legends, badge carriers |
| `translucent/` | POWER indicator |

Empty until CAD produces STLs/3MFs. Prefer exporting from refined B-Rep, not hand-edited meshes.
