# apple2js tooling (ESP][)

Developer-only utilities. Cache: `.cache/apple2js/` (gitignored).

```
node dev/tools/apple2js/cli.mjs sync
node dev/tools/apple2js/cli.mjs catalog
node dev/tools/apple2js/cli.mjs audit
```

Or via µGulp: `apple2js:sync`, `apple2js:catalog`, `apple2js:audit`.

See `docs/media/apple2js.md`.
